# Orbhita
## Status backend
Backend menggunakan Supabase Edge Functions dengan TypeScript.
Endpoint GET /functions/v1/health sudah diuji dan menghasilkan HTTP 200
dengan status "ok". Endpoint ini bersifat publik dan tidak membaca data pengguna.
Integrasi Google Calendar belum diimplementasikan.

## Penggunaan AI
ChatGPT digunakan untuk membantu pembahasan arsitektur, setup backend,
penulisan fungsi health, dan penelusuran error. Kode health diperiksa
dan endpoint diuji oleh anggota tim melalui curl. Catatan ini akan
diperbarui sesuai penggunaan AI selama pengembangan.
